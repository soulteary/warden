# 版本化 Redis 快照协议

此存储 API 为增量能力；在显式开启迁移模式前，旧用户数组缓存及应用选择方式不变。

v2 保存生效用户、内容摘要、输入版本和数量、原始来源类型、来源成功时间、发布时间
及发布修订号。来源成功指一次被采纳的来源加载，不代表上游业务内容刚更新。恢复时间
属于本进程，不作为来源证据持久化。

每个数据集须显式指定命名空间及策略指纹。快照和租约使用同一 Redis Cluster hash tag。
读取原子地区分键缺失与合法空集；拒绝未知格式或策略、null 用户、错误摘要、异常时间
和过大载荷，错误不包含原始数据。允许最多五秒的未来时钟偏差。

写入者须在加载来源前取得 Redis 所有者令牌租约，发布时原子核对所有权。过期写入者
不能发布或删除继任者租约。租约有界且不自动续租，慢任务过期后跳过共享发布，下一
刷新周期重试。Redis 故障不降级为进程内所有权。

续期比较当前发布修订号，仅修改 TTL，不改写用户、来源成功时间或发布时间。
旧副本即使持有相同用户内容，也不能续期或恢复更新的发布。部署仍须保证时钟同步及
Redis 写入者可信；此格式不等同于带签名的上游版本协议。

协议测试使用 miniredis 的真实 Lua 执行，覆盖租约过期、继任者、陈旧续期、空集、
损坏快照及重启恢复。应用迁移和旧格式兼容由独立改动实现。
