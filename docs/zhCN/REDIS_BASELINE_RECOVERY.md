# 恢复缺失的 V2 基线

`REDIS_SNAPSHOT_MODE=v2` 下，没有已知有效快照的实例在来源加载或身份校验失败后重试共享 V2 基线。启动与后台刷新使用同样规则；恢复保留持久化的来源成功时间和发布时间，仅推进本地恢复时间。后台来源失败计数仍然保留。

恢复遵守现有 schema、策略、摘要与生效集合校验，不发布失败输入、不续期，也不替换已有有效集合（包括合法空集合）。陈旧基线仍以原时间计算新鲜度，查询缓存行为不变。

新增的失败恢复不适用于 legacy/shadow 或 ONLY_LOCAL 的来源失败。既有“全部记录被拒绝”处理不变。Redis 仍不可达或基线不兼容时保持无基线状态，在之后失败刷新时再次尝试。
